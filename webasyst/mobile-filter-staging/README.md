# Подготовленный Webasyst-патч мобильного фильтра

Это PR-артефакт для отдельной проверки. Он не является развёрнутой staging-витриной и не меняет GitHub Pages, Render, Timeweb или production.

Локальные checkpoint-коммиты с полной QA-фиксацией: `5e99fe5` и `15c8943`. PR содержит только минимальный патч и его детерминированный тест, без полного исходника темы и скриншотов.

## Изменение

В `category.html` шаблона Shop-Script мобильный шаблон фильтра подключается без серверного условия `$is_mobile`, при наличии `$filters`. CSS/Shop-Script продолжают отвечать за реальное отображение и обработку формы. Патч меняет одну строку. Полный исходник Handyshop в публичный репозиторий не копируется.

## Baseline и откат

Патч подготовлен к baseline SHA-256 `B3F6E7B3B27B78E87A4EB763454D085EA5801FB9AD7F42F4F3C01B83EDD20FF1`. Перед применением на отдельной копии темы требуется подтвердить SHA, создать резервную копию и после проверки откатить патч обратным diff либо восстановить исходный файл.

## Ограничения проверки

Кандидат ещё не скомпилирован Smarty и не установлен на Shop-Script staging. PR запускает только детерминированную проверку формы патча (один файл, одна строка замены, без секретов). Предыдущие Edge/Playwright результаты относятся к публичному baseline, не к исправленному шаблону. GitHub Pages — статический сайт, поэтому он не используется как замена полноценному Webasyst.

## Требования перед применением

Нужен штатный серверный канал чтения/записи Timeweb и изолированная копия Webasyst/Shop-Script с отдельной обезличенной БД, закрытой авторизацией, отключёнными платежами, уведомлениями и внешними интеграциями, а также запретом индексации. Производство и DNS этим PR не меняются.
