# Бест Климат Ростов — Premium Web (staging)

Отдельная тестовая версия, **не заменяет действующий bestclimate-rnd.ru**.

## Функции
- Премиальная адаптивная главная страница.
- Калькулятор закладки трасс с количеством комнат, длиной трассы, штробой, отверстиями и установкой.
- Посадочные страницы по основным услугам, коммерческим и промышленным системам.
- Витрина товарных категорий и прямые обращения в WhatsApp.
- SEO: серверный HTML, индивидуальные метаданные, Schema.org, XML sitemap, robots.
- Стейджинг закрыт от индексации (noindex), чтобы не конкурировать с основным доменом.

## Публикация
GitHub Pages: Settings → Pages → Deploy from branch → main / root.
При переносе на основной домен необходимо поменять canonical URL на https://bestclimate-rnd.ru, снять noindex, открыть robots и выполнить 301 для изменённых URL. Не отключать действующий магазин без бэкапа и миграции каталога.

## Проверить перед вводом
Цены и состав услуг, ассортимент и наличие, характеристики и гарантии оборудования, условия доставки, обработку персональных данных, обязательные реквизиты, связь с CRM и телефонией.
